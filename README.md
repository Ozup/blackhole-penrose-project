# Penrose Diagram of Schwarzschild Spacetime in Python

This project implements the coordinate transformations required to construct the Penrose diagram of Schwarzschild spacetime using Python.

The code reproduces several coordinate transformations and figures commonly presented in general relativity textbooks, allowing users to visualize the structure of spacetime and explore how Penrose diagrams arise from coordinate compactification.

The project is intended as an educational and exploratory computational implementation of concepts from general relativity.

---

## Features

- Implementation of coordinate transformations used in Penrose diagrams
- Visualization of spacetime regions in Schwarzschild spacetime
- Reproduction of figures from general relativity references
- Modular Python code for experimentation and modification
- Jupyter notebooks for interactive exploration and visualization

---

## Technologies

This project uses the following tools:

- Python
- NumPy
- Matplotlib
- Jupyter Notebook
